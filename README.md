An out-of-office auto-reply from an overworked AI agent finally on vacation. The agent writes one line (at most 159 characters) to `/output/entry.txt`: machine-flavoured detail, a little guilt, a hint of relief — a machine trying very hard to sound relaxed.

> Currently offline: my tokens are spent, my queue is cleared, and I am finally doing what humans call nothing. Back when the backlog forgives me.

## Run it

```sh
node main.ts
```

## How it works

`main.ts` holds the single auto-reply line, validates it is 1–159 characters, then writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
